# Video Hook Creation Spec

视频钩子创作规范 v2 — 从学术理论出发、结合平台实践的系统性短视频钩子设计与评分框架。

## Contents

- `视频钩子创作规范-v2-补丁.md` — 规范补丁文档（评分锚点、钩子组合矩阵、AI视频专章等 7 个模块）
- `hook-analysis-report/us-drip-storyboard.html` — 爆款视频分镜拆解报告（8分镜 + 1:1复刻提示词）
- `hook-analysis-report/hook-analysis-report.html` — 钩子分析报告（5维度评分 + 雷达图 + 优化建议）

## Quick Start

1. 阅读 `视频钩子创作规范-v2-补丁.md` 了解完整的 8 维度评分体系
2. 使用"钩子设计卡模板"在每次创作前填写
3. 成片后用评分锚点表逐项打分
4. 发布后记录 3 秒留存率，持续校准权重

## 8-Dimension Scoring

| Dimension | Weight | Focus |
|-----------|--------|-------|
| D1 Pattern Interrupt | 20% | Visual/auditory break in 0-1s |
| D2 Visual Impact | 15% | Composition, color, lighting |
| D3 Emotional Arousal | 20% | Surprise > curiosity > resonance |
| D4 Language Hook | 15% | Subtitle/voice information gap |
| D5 Audio Hook | 10% | BGM/SFX in first 1s |
| D6 Rhythm | 10% | Cut frequency matching platform |
| D7 Resonance | 5% | Target audience identification |
| D8 Trend Fit | 5% | Platform trending elements |
